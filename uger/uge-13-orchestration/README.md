# Uge 13 — Orchestration, Kubernetes & Resilience

> 📅 Dato: 29. april 2026

## 🎯 Læringsmål

- [ ] Kender forskellige deployment strategier og hvordan de fungerer
- [ ] Forstår begrebet orchestration og kan argumentere for vigtigheden af det
- [ ] Kender de grundlæggende begreber i Kubernetes
- [ ] Forstår vigtigheden af resilience i systemer og idéen bag chaos engineering

## 📌 Kernebegreber

| Begreb | Kort forklaring |
|--------|----------------|
| Orchestration | Automatisk styring af mange containers på tværs af servere |
| Kubernetes (K8s) | Industri-standard container orchestration platform |
| Deployment Strategy | Hvordan ny kode udrulles uden at brugerne mærker det |
| Resilience | Et systems evne til at håndtere og komme sig efter fejl |
| Chaos Engineering | Bevidst injektion af fejl for at teste systemets robusthed |
| IaC | Infrastructure as Code — infrastruktur beskrevet i kode |
| Rolling Update | Gradvis udskiftning af instanser under deploy |
| Blue/Green | To parallelle miljøer — skift trafik når ny version er klar |
