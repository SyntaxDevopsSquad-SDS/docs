## 📌 Kernebegreber
| Begreb | Kort forklaring |
|--------|----------------|
| Prometheus | Scraper metrics fra applikationer via HTTP endpoints |
| Grafana | Visualiseringsværktøj til Prometheus data |
| ELK Stack | Elasticsearch + Logstash + Kibana — logging platform |
| KPI | Key Performance Indicator — forretningsmæssig nøglemåling |
| Telemetry | Automatisk indsamlet data om systemets tilstand |
| Log Level | DEBUG, INFO, WARNING, ERROR, CRITICAL |
| Scraping | Prometheus henter metrics med faste intervaller |
